# Ideas

This directory is the knowledge base for proposed, experimental, superseded, or
not-yet-implemented API Notes designs.

Use versioned filenames when an idea evolves over time.

## Files

- `format_v1.md`: deprecated v1 prototype for C++ overload-aware API Notes
- `format_v2.md`: post-meeting v2 selector-model proposal with a bounded first implementation slice
- `format_v2_templates.md`: future C++ template-matching notes for the v2 selector model
