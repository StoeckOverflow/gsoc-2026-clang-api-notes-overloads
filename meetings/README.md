# Meetings

This directory contains meeting notes for the project.

Use this directory for:

- Raw or lightly cleaned meeting notes.
- Meeting agendas and questions.
- Discussion summaries.
- Open questions and follow-up items from meetings.

Distilled architecture knowledge should move into `../notes/`. Experimental or
future-facing design ideas should move into `../ideas/`.
