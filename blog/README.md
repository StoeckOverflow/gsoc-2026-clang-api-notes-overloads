# Blog And Diary

This directory contains the project diary, final report, and LLVM blogpost draft.

Use this directory for:

- Weekly progress notes.
- Short diary entries about what changed or what was investigated.
- Reflections after meetings.
- Drafts or polished blog posts about the project.
- Final project reporting material.

## Files

- `diary.md`: running diary for meetings, setup work, weekly progress, and
  investigation notes.
- `report.md`: final GSoC project report.
- `llvm_blogpost.md`: LLVM blogpost draft.
